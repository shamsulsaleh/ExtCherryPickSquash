# Changelog

## 0.1.0

First Marketplace release.

- **Cherry-Pick: Commits** view in the Source Control panel with multi-select.
- **Cherry-Pick to Branch...**: apply selected commits (oldest first) to an existing local/remote branch or a new branch.
- **Squash to Branch...**: combine selected commits into a single commit on the destination branch.
- Create a new destination branch from the current branch or from any local/remote branch.
- Conflict handling: pause, open conflicted files, then **Continue** / **Skip** / **Abort** from the status bar, notification, or view toolbar.
- Automatic stash of uncommitted changes, skip of already-applied (empty) commits, and session restore after a window reload.
